# Portal2026v2 使用指南

Portal2026v2 面向已 Root 的 Android 设备，重点提供固定位置设置。新版使用独立包名，可与原版应用并存；启用模块时请避免两套模块同时接管定位服务。

## 准备

1. 安装适用于设备架构的 APK，并在 LSPosed 中启用 Portal2026v2。
2. 在作用域中选择系统框架；支持的小米设备还需要选择融合定位和电话服务进程。修改作用域后重启设备。
3. 在应用中选择固定地点，检查坐标后启动。更换地点前先停止模拟。

可手动输入 WGS84、GCJ-02 或 BD-09 坐标。在线地图需要用户主动启用，网络请求可能向地图服务提供设备 IP、地图范围及请求信息；手动输入不依赖在线地图。

## 状态与隐私

系统服务连接和固定点状态只代表当前配置与服务的反馈，不等于所有应用的定位行为均已验证。运行时首页会核对系统回读的位置；若与已选地点不一致或暂时无法核对，页面会显示提示。系统定位权限和 AppOps 仍适用。

模拟位置不能覆盖所有可能的位置线索。IP 地址、蓝牙、应用缓存、网络服务、厂商接口和其他未覆盖的来源仍可能提供线索。停止模拟前应先关闭需要保护位置的应用；应按实际设备、系统版本和目标应用单独验证。

## 构建

需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.0、NDK 26.1.10909125 和 CMake 3.22.1。配置 Android SDK 后，在项目根目录运行：

```sh
./gradlew :app:assembleArm64Debug :app:testArm64DebugUnitTest :xposed:testDebugUnitTest
```

Debug APK 使用构建环境的 Debug 证书；覆盖安装已有应用需要相同签名。发布用途应使用由维护者妥善管理的独立签名密钥。
